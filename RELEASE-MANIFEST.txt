Important release fix
---------------------
Creating a valid rerun no longer marks the new execution or its newly attached evidence potentially stale merely because execution creation added its own traceability references. The execution-creation transaction suppresses impact generation for bookkeeping links while preserving normal controlled revisions, persistence, and later substantive impact detection.

Production startup
------------------
Serve the extracted production directory from HTTP or HTTPS:

  python3 -m http.server 4173

Open:

  http://localhost:4173

Do not rely on file:// for IndexedDB, service workers, offline caching, installation, or full file behavior.
